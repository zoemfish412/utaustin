# hero-split-video

Custom **hero** block. Purpose: Photo-background banner with a text column (heading, paragraph, button, large stats) and a looping video at the side.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: heading, paragraph, CTA link, stat paragraphs (**value** label) and a link to the video file (.mp4) — the video link may also sit in its own cell with an optional poster image.

No variations.
