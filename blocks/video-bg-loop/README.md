# video-bg-loop

Custom **video** block. Purpose: Full-bleed muted, looping background video with poster image and a pause/play toggle; no text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: poster image + link to the video file (.mp4/.webm), optional link to a .vtt description track; the video link text is the video title. Optional row 2: pause label | play label for the toggle button.

## Supported variations

No variations.
